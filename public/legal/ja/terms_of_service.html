利用規約

第1条（目的）

本規約は、株式会社SsoBig（以下「会社」）が運営するSsoBig Tool（以下「ツール」）で提供するオフラインの集まりの進行支援サービス（以下「サービス」）の利用における、会社と利用者の権利・義務および責任事項を定めることを目的とします。

第2条（定義）

  1. 「サービス」とは、会社が提供するオフラインの集まりのためのリアルタイム双方向サービスであり、ホストが作成したルームでゲストが投票、アンケート、マッチングなどの交流を行うためのすべての機能を含みます。
  2. 「利用者」とは、本サービスを利用するホストおよびゲストの総称です。
  3. 「ホスト」とは、サービス内でルームを作成・管理し、ゲストの参加を進行する権限を持つ会員をいいます。
  4. 「ゲスト」とは、ホストが作成したルームに参加してサービスを利用する者をいいます。
  5. 「会員」とは、サービスに会員登録し、継続してサービスを利用できる者をいいます。
  6. 「非会員」とは、会員登録をせずにゲストとして一時的にサービスを利用する者をいいます。

第3条（規約等の明示・説明および改定）

  1. 会社は、本規約の内容、商号、代表者氏名、営業所所在地（利用者の苦情を処理できる住所を含む）、電話番号、メールアドレス、事業者登録番号、個人情報管理責任者等を利用者が容易に確認できるよう、サービスの初期画面に掲載します。ただし、規約の内容はリンク先の画面で閲覧できるようにすることもできます。
  2. 会社は、利用者が規約に同意する前に、プライバシーポリシー等の重要な内容を理解できるよう、別のリンク先画面やポップアップ画面等を提供し、利用者の確認を求めなければなりません。
  3. 会社は、韓国の「情報通信網利用促進および情報保護等に関する法律」「個人情報保護法」「約款の規制に関する法律」「電子文書および電子取引基本法」「消費者基本法」等の関連法に違反しない範囲で、本規約を改定できます。
  4. 会社が規約を改定する場合、適用日および改定理由を明示し、現行規約とともにサービスの初期画面で適用日の7日前から前日まで告知します。利用者に不利な変更は、少なくとも30日以上の事前猶予期間を設けて告知します。この場合、改定前後の内容を明確に比較し、利用者に分かりやすく表示します。
  5. 本規約に定めのない事項および本規約の解釈は、韓国の「情報通信網利用促進および情報保護等に関する法律」「個人情報保護法」、約款の規制に関する法律、その他の関連法令または商慣習に従います。

第4条（サービスの提供および変更）

  1. 会社は、次のサービスを提供します。
    1. オフラインの集まりのためのリアルタイム双方向機能
    2. ホストによるルーム作成・管理機能
    3. ゲストによるルーム参加・交流機能
    4. その他、会社が定める付加サービス
  2. 会社は、技術仕様の変更等の理由でサービス内容を変更できます。その場合、変更後の内容および提供日を明示し、サービスの初期画面で直ちに告知します。
  3. 会社がサービス内容を変更する場合、その理由をメール等の通知可能な手段で利用者に直ちに通知します。
  4. 前項の場合、会社はこれにより利用者が被った損害を賠償します。ただし、会社が故意または過失のないことを立証した場合は、この限りではありません。

第5条（サービスの中断）

  1. 会社は、次の場合にサービスの提供を一時的に中断できます。
    1. システムの点検、保守、交換等が必要な場合
    2. 通信回線に障害が発生した場合
    3. 天災、停電、利用の集中等により正常なサービス提供が困難な場合
    4. その他の不可抗力が発生した場合
  2. 会社は、第1項の理由による一時的なサービス中断で利用者または第三者が被った損害を賠償します。ただし、会社が故意または過失のないことを立証した場合は、この限りではありません。
  3. 会社が業種の変更、事業の廃止、企業間の統合等によりサービスを提供できなくなる場合、第8条の方法で利用者に通知します。

第6条（会員登録）

  1. 利用者は、会社所定の登録フォームに会員情報を記入し、本規約に同意する意思を示すことで会員登録を申請します。
  2. 会社は、第1項に従って申請した利用者について、次のいずれかに該当しない限り会員として登録します。
    1. 申請者が過去に本規約第7条第3項により会員資格を失ったことがある場合
    2. 登録内容に虚偽、記入漏れ、誤記がある場合
    3. その他、会員登録が会社にとって技術上著しい支障となると判断される場合
  3. 会員登録契約は、会社の承諾が会員に到達した時点で成立します。
  4. 登録事項に変更があった場合、会員は会員情報の修正等により直ちに会社へ変更内容を通知しなければなりません。

第7条（退会および資格喪失等）

  1. 会員はいつでも退会を申請でき、会社は直ちに退会手続きを行います。
  2. 会員が次のいずれかに該当する場合、会社は会員資格を制限または停止できます。
    1. 登録申請時に虚偽の内容を登録した場合
    2. 他の利用者のサービス利用を妨害し、または情報を盗用した場合
    3. サービスを利用して、法令もしくは本規約で禁止される行為、または公序良俗に反する行為をした場合
    4. ゲストの個人情報を無断で収集・保存・公開した場合
    5. サービスの運営を故意に妨害した場合
    6. その他の関連法令に違反した場合
  3. 会社が会員資格を制限・停止した後、同じ行為が2回以上繰り返されるか、30日以内にその原因が是正されない場合、会社は会員資格を喪失させることができます。
  4. 会社が会員資格を喪失させる場合、会員登録を抹消します。その際、会員に通知し、抹消前に少なくとも30日以上の期間を設けて弁明の機会を与えます。

第8条（会員への通知）

  1. 会社は、会員が提供したメールアドレスまたは携帯電話番号に通知を送ることができます。
  2. 不特定多数の会員への通知は、サービス内のお知らせに1週間以上掲載することで個別通知に代えることができます。ただし、会員本人のサービス利用に重大な影響を及ぼす事項は個別に通知します。

第9条（サービス利用および個人情報提供への同意等）

  1. 会社は、サービスの利用に際し、次の内容を利用者に分かりやすく提供しなければなりません。
    1. サービスの主な機能および利用方法
    2. 収集する個人情報の項目（ニックネーム、電話番号等）
    3. 規約内容およびサービス利用制限の確認
    4. 本規約への同意および上記事項の確認または拒否の意思表示
  2. 会社が第三者に利用者の個人情報を提供する必要がある場合、次の事項を通知し、同意を得なければなりません。
    1. 個人情報の提供先
    2. 提供先の個人情報の利用目的
    3. 提供する個人情報の項目
    4. 提供先の個人情報の保有・利用期間
  3. 会社は、リアルタイムで収集される利用者のサービス利用データについて、収集範囲および利用目的を明確に告知しなければなりません。

第10条（サービス利用の成立）

  1. 会社は、次の場合にサービス利用を制限できます。
    1. 申請内容に虚偽、記入漏れ、誤記がある場合
    2. 他人の権利を侵害または盗用する場合
    3. その他、サービスの提供に技術上著しい支障があると判断される場合
  2. 未成年者がサービスを利用する場合、法定代理人の同意が必要です。同意が得られていない場合、未成年者本人または法定代理人は利用契約を取り消すことができます。

第11条（メンバーシップおよびトークンの購入）

  1. 会社のサービスの一部は、メンバーシップまたはトークンの購入により利用でき、支払方法は次のとおりです。
    1. クレジットカード決済
    2. 銀行振込
    3. 携帯電話決済
    4. その他、会社が定める電子的支払方法
  2. 会社は、利用者の支払方法について、いかなる名目の手数料も追加で徴収しません。
  3. メンバーシップおよびトークンの有効期間、利用条件、返金基準等は、各商品の購入時に別途告知します。
  4. チャージしたトークンの利用期間および返金可能期間は、決済時点から1年以内に限定されます。
  5. 未成年者がメンバーシップやトークンを購入する場合、法定代理人の同意が必要です。同意なく購入した場合、未成年者本人または法定代理人は購入を取り消すことができます。
  6. メンバーシップおよびトークンは、会社が定める目的および基準に従ってのみ利用でき、第三者への譲渡や現金への換金はできません。

第12条（メンバーシップおよびトークンの購入確認）

  1. 会社は、利用者からメンバーシップまたはトークンの購入申込みを受けた場合、購入確認を通知します。
  2. 購入確認を受けた利用者は、内容の不一致等がある場合、直ちに購入取消しを申請できます。会社は、メンバーシップまたはトークンが未使用の場合、遅滞なく申請に従って処理します。

第13条（メンバーシップおよびトークンの提供）

  1. 会社は、購入されたメンバーシップまたはトークンを決済完了後すぐに利用できるよう提供します。
  2. システム障害等により即時提供が困難な場合、会社はその理由と提供予定時期を利用者に通知します。

第14条（払戻し）

  1. 会社は、次の場合に利用者が支払った代金を払い戻します。
    1. システムエラーによりメンバーシップまたはトークンが提供されなかった場合
    2. サービスの中断により購入したメンバーシップを利用できなくなった場合
    3. その他、会社の責めに帰すべき事由によりサービスを提供できない場合
  2. 払戻しは代金を受け取った日から3営業日以内に行い、遅延した場合は関連法令に基づく遅延利息を併せて支払います。

第15条（申込みの撤回および返金）

  1. 利用者は、購入したメンバーシップまたはトークンを使用していない場合、購入日から7日以内に申込みを撤回できます。
  2. 次の場合、申込みの撤回が制限されることがあります。
    1. メンバーシップまたはトークンの使用が開始された場合
    2. 利用者の責めに帰すべき事由によりメンバーシップまたはトークンが失われた場合
    3. その他、取引の安全のために法令で定められた場合
  3. 申込み撤回時の返金は、利用者が使用した支払方法に応じて次のとおり処理します。
    1. クレジットカード：決済取消し
    2. 銀行振込：返金口座への入金
    3. 携帯電話決済：携帯電話会社による決済取消し、または返金口座への入金

第16条（個人情報の保護）

  1. 会社は、サービス提供に必要な範囲で最小限の個人情報を収集します。特に、オフラインの集まりのサービスという特性を考慮し、利用者のリアルタイムの参加情報および交流データを収集することがあります。
  2. 会社は、利用者の個人情報を収集・利用する際、その目的を告知し、同意を得ます。
  3. 会社は、収集した個人情報を目的外に利用できません。新たな利用目的が生じた場合や第三者に提供する場合、その目的を告知し、同意を得ます。
  4. 会社は、同意を得る際に次の事項を利用者に告知します。
    1. 個人情報管理責任者の身元
    2. 情報の収集目的および利用目的
    3. 第三者提供時の提供先、目的、項目
    4. リアルタイムで収集する情報の範囲および保管期間
  5. 利用者はいつでも自身の個人情報の閲覧および誤りの訂正を求めることができ、会社は遅滞なく必要な措置を取ります。
  6. 会社は、個人情報保護の管理責任者を置き、個人情報の紛失、盗難、漏えい、無断提供、改ざん等による利用者の損害に責任を負います。
  7. 会社は、サービスの目的が達成された個人情報を遅滞なく破棄します。

第17条（会社の義務）

  1. 会社は、関連法令および本規約を遵守し、安定したサービスの提供に最善を尽くします。
  2. 会社は、利用者が安全にサービスを利用できるようセキュリティシステムを備え、個人情報の保護に努めます。
  3. 会社は、サービス提供に関連して知り得た利用者の情報を、本人の承諾なく第三者に提供または漏えいしません。
  4. 会社は、利用者が望まないマーケティング情報を送信しません。

第18条（会員のアカウント管理義務）

  1. IDおよびパスワードの管理責任は会員にあります。
  2. 会員は、自身のIDおよびパスワードを第三者に提供したり、使用させたりしてはなりません。
  3. IDおよびパスワードの盗用や第三者による使用を認識した場合、会員は直ちに会社に通知し、その案内に従わなければなりません。
  4. 会員は、自身のアカウントで行われるすべての活動に責任を負います。

第19条（利用者の義務）

利用者は、次の行為をしてはなりません。

  1. 会員登録や情報変更時に虚偽の内容を登録する行為
  2. 他人の情報を盗用または無断で使用する行為
  3. サービス内の情報を無断で変更または削除する行為
  4. 悪意あるプログラムの設置・配布、またはサービスの正常な運営を妨害する行為
  5. 会社および第三者の知的財産権を侵害する行為
  6. 他人の名誉を傷つけ、または集まりの進行を妨害する行為
  7. わいせつ、暴力的、差別的、または公序良俗に反する内容の情報を掲載・送信する行為
  8. 営利目的の広告情報を掲載・送信する行為
  9. リアルタイムの投票やアンケートの結果を操作・歪曲する行為
  10. 他の利用者の個人情報を無断で収集・保存・公開する行為
  11. オフラインの集まりの安全や秩序を損なう行為
  12. その他、関連法令で禁止される行為、またはサービスの正常な運営を妨害する行為

第20条（著作権の帰属および利用制限）

  1. 会社が制作したサービス内のコンテンツに関する著作権およびその他の知的財産権は、会社に帰属します。
  2. 利用者がサービス内で作成したコンテンツの著作権は利用者に帰属します。ただし、会社は、サービスの運営、展示、広報、改善等のため、利用者のコンテンツを無償で使用できます。
  3. 利用者は、会社の事前承諾なく、サービスを通じて得た情報を複製、送信、出版、配布、放送その他の方法で営利目的に利用し、または第三者に利用させてはなりません。

第21条（紛争解決）

  1. 会社は、利用者の正当な意見や苦情を反映し、その被害の補償を処理するため、カスタマーサポートを運営します。
  2. 会社は、利用者から提出された苦情や意見を優先的に処理します。迅速な処理が難しい場合、その理由および処理予定を直ちに利用者へ通知します。
  3. 会社と利用者の間の紛争について利用者から被害救済の申請があった場合、関連法令に基づく紛争調整機関の調整に従うことができます。

第22条（裁判管轄および準拠法）

  1. 会社と利用者の間の紛争に関する訴訟は、提訴時の利用者の住所を管轄する地方裁判所、住所がない場合は居所を管轄する地方裁判所の専属管轄とします。ただし、提訴時の住所・居所が不明な場合、または海外居住者の場合は、韓国の民事訴訟法に基づく管轄裁判所に提起します。
  2. 会社と利用者の間の訴訟には、大韓民国の法律を適用します。

第23条（Alimtalk等のメッセージ送信）

会社は、サービス運営に関する案内、通知、集まりへの参加情報等をKakaoTalkのAlimtalkで送信できます。Alimtalkを受信できない場合やブロックされている場合は、SMSで送信します。モバイル通信網で受信する際、データ通信料が発生することがあります。Alimtalkの受信を希望しない場合、ブロックするか、別の方法での情報受信を会社に依頼できます。

附則

本規約は2024年12月4日から施行します。
