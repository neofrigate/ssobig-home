服务条款

第1条（目的）

本条款旨在规定用户使用SsoBig股份有限公司（以下简称“公司”）运营的SsoBig Tool（以下简称“工具”）所提供的线下聚会主持辅助服务（以下简称“服务”）时，公司与用户的权利、义务及责任。

第2条（定义）

  1. “服务”指公司提供的用于线下聚会的实时互动服务，包括嘉宾在主持人创建的房间内进行投票、问卷、配对等各种互动的所有功能。
  2. “用户”统指使用本服务的主持人和嘉宾。
  3. “主持人”指有权在服务内创建和管理房间、引导嘉宾参与的会员。
  4. “嘉宾”指加入主持人创建的房间并使用服务的人。
  5. “会员”指已注册服务并可持续使用服务的人。
  6. “非会员”指未注册会员，以嘉宾身份临时使用服务的人。

第3条（条款等的公示、说明及修订）

  1. 公司在服务初始页面公示本条款内容、商号、代表人姓名、营业地址（包括可处理用户投诉的地址）、电话号码、电子邮箱、营业登记号及个人信息管理负责人等，便于用户了解。但条款内容可通过链接页面提供。
  2. 在用户同意条款前，公司应提供单独的链接页面或弹窗等，使用户理解隐私政策等重要内容，并请用户确认。
  3. 公司可在不违反韩国《信息通信网利用促进及信息保护等相关法律》《个人信息保护法》《格式条款规制法》《电子文书及电子交易基本法》《消费者基本法》等相关法律的范围内修订本条款。
  4. 修订条款时，公司应注明生效日期及修订原因，并将其与现行条款一起在服务初始页面自生效前7日至前一日公示。对用户不利的变更应至少提前30日公示，并明确对比修订前后内容，便于用户理解。
  5. 本条款未规定的事项及条款解释，依照韩国《信息通信网利用促进及信息保护等相关法律》《个人信息保护法》、有关格式条款规制的法律及相关法令或商业惯例处理。

第4条（服务的提供及变更）

  1. 公司提供以下服务：
    1. 线下聚会实时互动功能
    2. 主持人创建及管理房间功能
    3. 嘉宾加入房间及互动功能
    4. 公司规定的其他附加服务
  2. 公司可因技术规格变更等原因变更服务内容，并立即在服务初始页面明确公示变更后的服务内容及提供日期。
  3. 变更服务内容时，公司应通过电子邮件等可用方式立即向用户通知原因。
  4. 前款情况下，公司应赔偿因此给用户造成的损失，但公司证明其无故意或过失的除外。

第5条（服务中断）

  1. 出现以下情形时，公司可暂时中断服务：
    1. 需要进行系统检查、维护、更换等
    2. 通信线路发生故障
    3. 自然灾害、停电、使用量激增等导致无法正常提供服务
    4. 发生其他不可抗力事件
  2. 因第1款所述原因暂时中断服务而给用户或第三方造成损失的，公司应予赔偿，但公司证明其无故意或过失的除外。
  3. 因业务转型、停止经营、企业合并等原因无法继续提供服务时，公司应按第8条规定的方式通知用户。

第6条（会员注册）

  1. 用户按公司规定的注册表填写会员信息，并表示同意本条款，即可申请注册会员。
  2. 对于按第1款申请注册的用户，除以下情形外，公司将其登记为会员：
    1. 申请人曾依本条款第7条第3款丧失会员资格
    2. 注册内容存在虚假、遗漏或错误
    3. 其他被认为会给公司的技术运营造成重大障碍的情形
  3. 会员注册合同自公司的承诺到达会员时成立。
  4. 注册信息发生变化时，会员应立即通过修改会员信息等方式通知公司。

第7条（注销会员及资格丧失等）

  1. 会员可随时申请注销，公司将立即办理。
  2. 会员存在以下情形时，公司可限制或暂停其会员资格：
    1. 注册申请时填写虚假内容
    2. 妨碍其他用户使用服务或盗用其信息
    3. 利用服务从事法律或本条款禁止的行为，或违反公序良俗的行为
    4. 擅自收集、保存、公开嘉宾的个人信息
    5. 故意妨碍服务运营
    6. 其他违反相关法律法规的行为
  3. 会员资格被限制或暂停后，如相同行为再次发生2次以上，或30日内未纠正相关原因，公司可取消其会员资格。
  4. 公司取消会员资格时，将注销其会员登记。公司应通知会员，并在注销前给予至少30日的申辩机会。

第8条（向会员发出通知）

  1. 公司可通过会员提供的电子邮箱或手机号码发送通知。
  2. 向不特定多数会员发出通知时，公司可在服务内公告至少1周，以代替逐一通知。但对会员本人使用服务有重大影响的事项，应单独通知。

第9条（服务使用及个人信息提供同意等）

  1. 公司应就服务使用向用户清晰提供以下内容：
    1. 服务的主要功能及使用方法
    2. 收集的个人信息项目（昵称、电话号码等）
    3. 确认条款内容及服务使用限制
    4. 表示同意本条款，并确认或拒绝上述事项
  2. 公司需要向第三方提供用户个人信息时，应告知以下事项并取得同意：
    1. 个人信息接收方
    2. 接收方使用个人信息的目的
    3. 提供的个人信息项目
    4. 接收方保留及使用个人信息的期限
  3. 公司应明确告知实时收集的用户服务使用数据的收集范围及使用目的。

第10条（服务使用的成立）

  1. 公司可在以下情形限制服务使用：
    1. 申请内容存在虚假、遗漏或错误
    2. 侵害或盗用他人权利
    3. 其他被认为会给服务提供造成重大技术障碍的情形
  2. 未成年人使用服务应取得法定代理人的同意。未取得同意的，未成年人本人或法定代理人可撤销使用合同。

第11条（会员资格及代币的购买）

  1. 部分服务需购买会员资格或代币后使用，付款方式如下：
    1. 信用卡付款
    2. 银行转账
    3. 手机账单付款
    4. 公司规定的其他电子支付方式
  2. 公司不会就用户的付款方式以任何名义加收手续费。
  3. 会员资格和代币的有效期限、使用条件及退款标准等，将在购买各商品时另行告知。
  4. 充值代币的使用期限及可退款期限均限制在付款之时起1年以内。
  5. 未成年人购买会员资格或代币应取得法定代理人的同意。未经同意购买的，未成年人本人或法定代理人可撤销购买。
  6. 会员资格和代币仅可按公司规定的目的及标准使用，不得转让给第三方或兑换现金。

第12条（会员资格及代币的购买确认）

  1. 用户申请购买会员资格或代币时，公司将向用户发送购买确认通知。
  2. 用户收到购买确认通知后，如发现内容不符等问题，可立即申请取消购买。会员资格或代币尚未使用的，公司将及时按申请处理。

第13条（会员资格及代币的提供）

  1. 公司在付款完成后立即提供所购会员资格或代币供用户使用。
  2. 因系统故障等原因无法立即提供时，公司应向用户通知原因及预计提供时间。

第14条（退还款项）

  1. 出现以下情形时，公司退还用户支付的款项：
    1. 系统错误导致未提供会员资格或代币
    2. 服务中断导致所购会员资格无法使用
    3. 因其他可归责于公司的原因无法提供服务
  2. 退款应在收到款项之日起3个工作日内完成。逾期退款时，应按相关法律支付逾期利息。

第15条（撤回购买及退款）

  1. 所购会员资格或代币未使用的，用户可在购买之日起7日内撤回购买。
  2. 以下情形可能限制撤回购买：
    1. 已开始使用会员资格或代币
    2. 因可归责于用户的原因造成会员资格或代币损失
    3. 法律为保障交易安全规定的其他情形
  3. 撤回购买时，退款按用户所用付款方式处理如下：
    1. 信用卡：取消付款
    2. 银行转账：汇入退款账户
    3. 手机账单付款：通过运营商取消付款或汇入退款账户

第16条（个人信息保护）

  1. 公司仅在提供服务所需范围内收集最少量的个人信息。考虑到线下聚会服务的特性，可收集用户的实时参与信息及互动数据。
  2. 公司收集、使用个人信息时，应告知用户目的并取得同意。
  3. 公司不得将收集的个人信息用于目的以外的用途。出现新用途或向第三方提供时，应告知用户目的并取得同意。
  4. 取得同意时，公司应向用户告知：
    1. 个人信息管理负责人的身份
    2. 信息收集及使用目的
    3. 向第三方提供时的接收方、目的及项目
    4. 实时收集信息的范围及保留期限
  5. 用户可随时请求查阅及更正本人的个人信息，公司将及时采取必要措施。
  6. 公司设立个人信息保护管理负责人，并对个人信息遗失、被盗、泄露、擅自提供、篡改等给用户造成的损失承担责任。
  7. 服务目的达成后，公司将及时销毁个人信息。

第17条（公司的义务）

  1. 公司遵守相关法律及本条款，尽力提供稳定的服务。
  2. 公司建立安全系统，保障用户安全使用服务，并努力保护个人信息。
  3. 未经用户本人同意，公司不得向第三方提供或泄露在提供服务过程中获知的用户信息。
  4. 公司不发送用户不希望接收的营销信息。

第18条（会员的账户管理义务）

  1. 会员负责管理本人的ID及密码。
  2. 会员不得向第三方提供自己的ID及密码，或允许第三方使用。
  3. 会员发现ID或密码被盗用或由第三方使用时，应立即通知公司并遵照公司指引。
  4. 会员对其账户发生的所有活动负责。

第19条（用户的义务）

用户不得从事以下行为：

  1. 注册会员或变更信息时填写虚假内容
  2. 盗用或未经许可使用他人信息
  3. 擅自更改或删除服务内的信息
  4. 安装、传播恶意程序或妨碍服务正常运营
  5. 侵犯公司或第三方的知识产权
  6. 损害他人名誉或妨碍聚会进行
  7. 发布或传送淫秽、暴力、歧视性或违反公序良俗的信息
  8. 发布或传送以营利为目的的广告信息
  9. 操纵或歪曲实时投票或问卷结果
  10. 擅自收集、保存或公开其他用户的个人信息
  11. 危害线下聚会的安全或秩序
  12. 其他法律禁止或妨碍服务正常运营的行为

第20条（著作权归属及使用限制）

  1. 公司制作的服务内内容的著作权及其他知识产权归公司所有。
  2. 用户在服务内创作的内容，其著作权归用户所有。但公司可为服务运营、展示、宣传、改进等目的免费使用该内容。
  3. 未经公司事先同意，用户不得通过复制、传送、出版、分发、广播或其他方式，将通过服务获得的信息用于营利目的，或允许第三方如此使用。

第21条（争议解决）

  1. 公司设立客服中心，以处理用户提出的合理意见或投诉，并办理损害赔偿事宜。
  2. 公司优先处理用户提交的投诉及意见。如难以及时处理，应立即告知用户原因及处理安排。
  3. 用户就与公司之间的争议申请救济时，可依相关法律接受争议调解机构的调解。

第22条（司法管辖及适用法律）

  1. 公司与用户之间争议的诉讼，由起诉时用户住所所在地的地方法院专属管辖；无住所的，由居所所在地地方法院管辖。但起诉时住所或居所不明，或用户居住在国外的，应向韩国《民事诉讼法》规定的管辖法院提起诉讼。
  2. 公司与用户之间的诉讼适用大韩民国法律。

第23条（Alimtalk等消息发送）

公司可通过KakaoTalk Alimtalk发送服务运营指引、通知及聚会参与信息等。如无法接收Alimtalk或已屏蔽，将通过短信发送。通过移动网络接收消息时可能产生流量费。不希望接收Alimtalk的用户可将其屏蔽，或要求公司通过其他方式提供信息。

附则

本条款自2024年12月4日起施行。
