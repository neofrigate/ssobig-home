利用規約

この日本語版は参考用の翻訳です。本翻訳と韓国語の原文との間に相違がある場合は、韓国語版が優先します。

第1条（目的）

本規約は、株式会社SSOBIG（以下「当社」）が運営するSsoBig Tool（以下「ツール」）において 提供するオフラインの集まりの進行支援サービス（以下「サービス」）の利用に関し、当社と 利用者の権利・義務および責任事項を定めることを目的とします。

第2条（定義）

  1. 「サービス」とは、当社が提供するオフラインの集まりの進行のためのリアルタイム・ インタラクティブサービスであって、ホストが作成したルームにおいてゲストが投票、 アンケート、マッチング等のさまざまなインタラクションを行うことができるすべての機能を 含みます。
  2. 「利用者」とは、本サービスを利用するホストおよびゲストを総称します。
  3. 「ホスト」とは、サービス内でルームを作成・管理し、ゲストの参加を主導する権限を有する 会員をいいます。
  4. 「ゲスト」とは、ホストが作成したルームに参加してサービスを利用する者を いいます。
  5. 「会員」とは、サービスに会員登録を行い、継続的にサービスを利用することができる 者をいいます。
  6. 「非会員」とは、会員登録を行わずに、ゲストとして一時的にサービスを利用する 者をいいます。

第3条（規約等の明示、説明および改定）

  1. 当社は、本規約の内容、商号および代表者氏名、営業所の所在地住所（利用者の苦情を処理する ことができる場所の住所を含みます）、電話番号、電子メールアドレス、事業者登録番号、 個人情報管理責任者等を、利用者が容易に知ることができるよう、サービスの初期画面に 掲示します。ただし、規約の内容は、利用者がリンク画面を通じて閲覧できるようにすることが できます。
  2. 当社は、利用者が規約に同意する前に、個人情報処理方針等の重要な内容を利用者が理解 できるよう、別途のリンク画面またはポップアップ画面等を提供し、利用者の確認を求めなければ なりません。
  3. 当社は、「情報通信網利用促進及び情報保護等に関する法律」、「個人情報保護法」、 「約款の規制に関する法律」、「電子文書及び電子取引基本法」、「消費者基本法」等の 関連法に違反しない範囲で、本規約を改定することができます。
  4. 当社が規約を改定する場合には、適用日および改定理由を明示し、現行規約とともに サービスの初期画面に、その適用日の7日前から適用日の前日まで告知します。ただし、 利用者に不利に規約の内容を変更する場合には、少なくとも30日以上の事前猶予期間を設けて 告知します。この場合、当社は、改定前の内容と改定後の内容を明確に比較し、利用者が 分かりやすいように表示します。
  5. 本規約に定めのない事項および本規約の解釈については、「情報通信網利用促進及び 情報保護等に関する法律」、「個人情報保護法」、「約款の規制等に関する法律」および 関係法令または商慣習に従います。

第4条（サービスの提供および変更）

  1. 当社は、次のサービスを提供します。
    1. オフラインの集まりのためのリアルタイム・インタラクティブ機能の提供
    2. ホストによるルームの作成および管理機能の提供
    3. ゲストによるルームへの参加およびインタラクション機能の提供
    4. その他当社が定める付加サービス
  2. 当社は、技術的仕様の変更等の事由により、サービスの内容を変更することが できます。この場合には、変更されたサービスの内容および提供日を明示して、 サービスの初期画面に直ちに告知します。
  3. 当社がサービスの内容を変更する場合には、その事由を利用者に電子メール等の通知可能な 手段により直ちに通知します。
  4. 前項の場合、当社は、これにより利用者が被った損害を賠償します。 ただし、当社が故意または過失がないことを証明した場合は、この限りでは ありません。

第5条（サービスの中断）

  1. 当社は、次の各号の場合には、サービスの提供を一時的に中断することが できます。
    1. システムの点検、保守、交換等が必要な場合
    2. 通信回線に障害が発生した場合
    3. 天災地変、停電、利用量の急増等により正常なサービスの提供が困難な 場合
    4. その他不可抗力による事由が発生した場合
  2. 当社は、第1項の事由によりサービスの提供が一時的に中断されたことにより 利用者または第三者が被った損害について賠償します。ただし、当社が故意 または過失がないことを証明した場合は、この限りではありません。
  3. 当社が事業種目の転換、事業の放棄、企業間の統合等の理由により サービスを提供できなくなった場合には、第8条に定める方法により利用者に 通知します。

第6条（会員登録）

  1. 利用者は、当社が定める登録様式に従って会員情報を記入した後、本 規約に同意する旨の意思表示をすることにより、会員登録を申し込みます。
  2. 当社は、第1項のとおり会員登録を申し込んだ利用者のうち、次の各 号に該当しない限り、会員として登録します。
    1. 登録申込者が本規約第7条第3項により以前に会員資格を 喪失したことがある場合
    2. 登録内容に虚偽、記載漏れ、誤記がある場合
    3. その他会員として登録することが当社の技術上著しく支障があると 判断される場合
  3. 会員登録契約の成立時期は、当社の承諾が会員に到達した時点と します。
  4. 会員は、会員登録時に登録した事項に変更がある場合、直ちに当社に 対し、会員情報の修正等の方法によりその変更事項を知らせなければなりません。

第7条（会員の退会および資格喪失等）

  1. 会員は、当社に対していつでも退会を要請することができ、当社は直ちに 会員退会を処理します。
  2. 会員が次の各号の事由に該当する場合、当社は会員資格を制限および 停止することができます。
    1. 登録申込時に虚偽の内容を登録した場合
    2. 他の利用者のサービス利用を妨害し、またはその情報を盗用した場合
    3. サービスを利用して、法令もしくは本規約が禁止する行為または公序良俗に反する 行為を行った場合
    4. ゲストの個人情報を無断で収集、保存、公開した場合
    5. サービスの運営を故意に妨害した場合
    6. その他関連法令に違反する行為を行った場合
  3. 当社が会員資格を制限、停止した後、同一の行為が2回以上 繰り返され、または30日以内にその事由が是正されない場合、当社は 会員資格を喪失させることができます。
  4. 当社が会員資格を喪失させる場合には、会員登録を抹消します。この場合、 会員にその旨を通知し、会員登録の抹消前に少なくとも30日以上の期間を 定めて弁明の機会を与えます。

第8条（会員に対する通知）

  1. 当社が会員に対して通知を行う場合、会員が提供した電子メールアドレスまたは 携帯電話番号に対して行うことができます。
  2. 当社は、不特定多数の会員に対する通知の場合、1週間以上サービス内の お知らせに掲示することにより、個別の通知に代えることができます。ただし、会員 本人のサービス利用に関して重大な影響を及ぼす事項については、 個別に通知します。

第9条（サービスの利用および個人情報提供への同意等）

  1. 当社は、サービスの利用にあたり、次の内容を利用者が分かりやすいように提供しなければ なりません。
    1. サービスの主な機能および利用方法
    2. 個人情報の収集項目（ニックネーム、電話番号等）
    3. 規約の内容、サービス利用の制限事項に関する確認
    4. 本規約に同意し、上記事項を確認し、または拒否する意思表示
  2. 当社が第三者に利用者の個人情報を提供する必要がある場合、次の各 号の事項を利用者に知らせ、同意を得なければなりません。
    1. 個人情報の提供を受ける者
    2. 個人情報の提供を受ける者の個人情報の利用目的
    3. 提供する個人情報の項目
    4. 個人情報の提供を受ける者の個人情報の保有および利用期間
  3. 当社は、リアルタイムで収集される利用者のサービス利用データについて、収集 範囲および利用目的を明確に告知しなければなりません。

第10条（サービス利用の成立）

  1. 当社は、次の各号に該当する場合、サービスの利用を制限することができます。
    1. 申込内容に虚偽、記載漏れ、誤記がある場合
    2. 他人の権利を侵害し、または盗用する場合
    3. その他サービスの提供に技術上著しい支障があると判断される場合
  2. 未成年者がサービスを利用する場合には、法定代理人の同意を得なければならず、 これを得られなかった場合、未成年者本人または法定代理人は利用契約を取り消す ことができます。

第11条（メンバーシップおよびトークンの購入）

  1. 当社のサービスの一部は、メンバーシップまたはトークンの購入を通じて利用することが でき、決済方法は次の各号のとおりです。
    1. クレジットカード決済
    2. 口座振替
    3. 携帯電話決済
    4. その他当社が定める電子的支払方法
  2. 当社は、利用者の決済方法について、いかなる名目の手数料も追加で 徴収しません。
  3. メンバーシップおよびトークンの有効期間、使用条件、返金基準等については、各商品の 購入時に別途告知します。
  4. チャージされたトークンの利用期間および返金可能期間は、決済時点から1年以内に 制限されます。
  5. 未成年者がメンバーシップまたはトークンを購入する場合、法定代理人の同意を得なければ ならず、同意なく購入した場合、未成年者本人または法定代理人は購入を 取り消すことができます。
  6. メンバーシップおよびトークンは、当社が定めた目的および基準に従ってのみ使用することができ、 これを第三者に譲渡し、または現金に換金することはできません。

第12条（メンバーシップおよびトークンの購入確認）

  1. 当社は、利用者からメンバーシップまたはトークンの購入申込みがあった場合、利用者に 購入確認の通知を行います。
  2. 購入確認の通知を受けた利用者は、内容の不一致等がある場合には直ちに購入の 取消しを要請することができ、当社は、メンバーシップまたはトークンが使用されていない 場合、遅滞なくその要請に従って処理します。

第13条（メンバーシップおよびトークンの提供）

  1. 当社は、利用者が購入したメンバーシップまたはトークンを、決済完了後直ちに利用することが できるよう提供します。
  2. 当社は、システム障害等の事由により直ちに提供することが困難な場合、その事由および提供 予定時点を利用者に通知します。

第14条（払戻し）

  1. 当社は、次の各号の場合、利用者が支払った代金を払い戻します。
    1. システムエラーによりメンバーシップまたはトークンが提供されなかった場合
    2. サービスの中断により購入したメンバーシップを使用できなくなった場合
    3. その他当社の責めに帰すべき事由によりサービスを提供できない場合
  2. 払戻しは、代金を受領した日から3営業日以内に行われ、払戻しが遅延した 場合には、関連法令に基づく遅延利息をあわせて支払います。

第15条（申込みの撤回および返金）

  1. 利用者は、購入したメンバーシップまたはトークンを使用していない場合、購入日から 7日以内に申込みの撤回を行うことができます。
  2. 次の各号の場合には、申込みの撤回が制限されることがあります。
    1. メンバーシップまたはトークンの使用が開始された場合
    2. 利用者の責めに帰すべき事由によりメンバーシップまたはトークンが失われた場合
    3. その他取引の安全のために法令で定める場合
  3. 申込みの撤回時の返金は、利用者が使用した決済手段に応じて、次のとおり 処理されます。
    1. クレジットカード：決済の取消し
    2. 口座振替：返金口座への入金
    3. 携帯電話決済：移動通信事業者による決済の取消し、または返金口座への入金

第16条（個人情報保護）

  1. 当社は、利用者の個人情報を収集する際、サービスの提供のために必要な範囲で 最小限の個人情報を収集します。特に、オフラインの集まりのサービスの特性を 考慮し、利用者のリアルタイムの参加情報およびインタラクションデータを収集することが あります。
  2. 当社は、利用者の個人情報を収集・利用するときは、利用者にその目的を 告知し、同意を得ます。
  3. 当社は、収集した個人情報を目的外の用途に利用することはできず、新たな 利用目的が生じた場合または第三者に提供する場合には、利用者にその目的を 告知し、同意を得ます。
  4. 当社は、利用者の同意を得る場合、次の事項を利用者に告知します。
    1. 個人情報管理責任者の身元
    2. 情報の収集目的および利用目的
    3. 第三者提供時の提供を受ける者、目的、項目
    4. リアルタイムで収集される情報の範囲および保管期間
  5. 利用者は、いつでも自己の個人情報について閲覧および誤りの訂正を求めることが でき、当社は遅滞なく必要な措置を講じます。
  6. 当社は、利用者の個人情報保護のために管理責任者を置き、個人情報の 紛失、盗難、流出、無断提供、改ざん等による利用者の損害について 責任を負います。
  7. 当社は、サービスの目的が達成された個人情報を遅滞なく破棄します。

第17条（当社の義務）

  1. 当社は、関連法令および本規約を遵守し、安定的にサービスを提供することに 最善を尽くします。
  2. 当社は、利用者が安全にサービスを利用できるよう、セキュリティシステムを 備え、個人情報保護に努めます。
  3. 当社は、サービスの提供に関連して知り得た利用者の情報を、本人の承諾 なく第三者に提供し、または漏えいしません。
  4. 当社は、利用者が望まないマーケティング情報を送信しません。

第18条（会員のアカウント管理義務）

  1. IDおよびパスワードに関する管理責任は会員にあります。
  2. 会員は、自己のIDおよびパスワードを第三者に提供し、または利用させてはなり ません。
  3. 会員は、IDおよびパスワードの盗用または第三者による使用を認識した場合、直ちに 当社に通知し、当社の案内に従わなければなりません。
  4. 会員は、自己のアカウントで発生するすべての活動について責任を負います。

第19条（利用者の義務）

利用者は、次の行為をしてはなりません。

  1. 会員登録、情報変更時における虚偽内容の登録
  2. 他人の情報の盗用または無断使用
  3. サービス内の情報の無断変更または削除
  4. 悪意のあるプログラムのインストール、配布またはサービスの正常な運営を妨害する行為
  5. 当社および第三者の知的財産権の侵害
  6. 他人の名誉を毀損し、または集まりの進行を妨害する行為
  7. わいせつ、暴力的、差別的な内容または公序良俗に反する内容の情報を 掲示し、または送信する行為
  8. 営利目的の広告性情報を掲示し、または送信する行為
  9. リアルタイム投票やアンケートの結果を操作し、または歪曲する行為
  10. 他の利用者の個人情報を無断で収集、保存、公開する行為
  11. オフラインの集まりの安全または秩序を害する行為
  12. その他関連法令で禁止され、またはサービスの正常な運営を妨害する行為

第20条（著作権の帰属および利用制限）

  1. 当社が制作したサービス内のコンテンツに関する著作権その他の知的財産権は、 当社に帰属します。
  2. 利用者がサービス内で作成したコンテンツの著作権は、利用者に帰属します。 ただし、当社は、サービスの運営、展示、広報、サービス改善等のために、 利用者のコンテンツを無償で使用することができます。
  3. 利用者は、当社のサービスを通じて得た情報を、当社の事前の承諾なく、 複製、送信、出版、配布、放送その他の方法により営利目的で 利用し、または第三者に利用させてはなりません。

第21条（紛争解決）

  1. 当社は、利用者が提起する正当な意見や苦情を反映し、その被害を 補償処理するため、カスタマーセンターを運営します。
  2. 当社は、利用者から提出される苦情事項および意見を優先的に 処理します。ただし、迅速な処理が困難な場合には、利用者にその事由および 処理日程を直ちに通知します。
  3. 当社と利用者との間に生じた紛争に関して、利用者から被害救済の申請が あった場合には、関連法令に基づく紛争調停機関の調停に従うことができます。

第22条（裁判権および準拠法）

  1. 当社と利用者との間に生じた紛争に関する訴訟は、提訴時の利用者の 住所により、住所がない場合には居所を管轄する地方法院の 専属管轄とします。ただし、提訴時に利用者の住所もしくは居所が明らかで ない場合または外国居住者の場合には、民事訴訟法上の管轄裁判所に提起します。
  2. 当社と利用者との間に提起された訴訟には、大韓民国法を適用します。

第23条（お知らせトーク等のメッセージ送信に関する内容）

当社は、サービスの運営に関する案内、通知事項、集まりへの参加情報等を、 カカオトークのお知らせトークで送信することがあり、お知らせトークを受信できない場合 または受信がブロックされている場合には、SMSで送信します。移動通信網で接続している場合、 メッセージの受信中にデータ通信料が発生することがあります。お知らせトークの受信を希望 しない場合は、お知らせトークをブロックし、または当社に他の方法による情報の受信を 要請することができます。

附則
