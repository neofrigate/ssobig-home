服务条款

本中文版本仅供参考。如本译文与韩文原文存在任何不一致，以韩文版本为准。

第1条（目的）

本条款旨在规定在使用由SSOBIG株式会社（以下简称“公司”）运营的SsoBig Tool（以下简称“工具”）所提供的线下聚会进行支持服务（以下简称“服务”）时，公司与用户之间的权利、义务及责任事项。

第2条（定义）

  1. “服务”是指公司为进行线下聚会而提供的实时互动服务，包括嘉宾可在主持人创建的房间内进行投票、问卷调查、匹配等各种互动的全部功能。
  2. “用户”是对使用本服务的主持人和嘉宾的统称。
  3. “主持人”是指在服务内拥有创建和管理房间、引导嘉宾参与之权限的会员。
  4. “嘉宾”是指参与主持人所创建的房间并使用服务的人。
  5. “会员”是指已在服务中注册会员并可持续使用服务的人。
  6. “非会员”是指未注册会员而以嘉宾身份临时使用服务的人。

第3条（条款等的明示、说明及修订）

  1. “公司”将本条款的内容以及商号及代表人姓名、营业场所所在地地址（包括可处理用户投诉的场所地址）、电话号码、电子邮件地址、营业执照号码、个人信息管理负责人等，公示于服务的初始画面，以便用户轻松了解。但条款的内容可设置为由用户通过链接画面查看。
  2. “公司”应在用户同意条款之前，另行提供链接画面或弹出画面等，以便用户理解隐私政策等重要内容，并征求用户的确认。
  3. “公司”可在不违反《促进信息通信网利用及信息保护等相关法律》、《个人信息保护法》、《关于条款规制的法律》、《电子文件及电子交易基本法》、《消费者基本法》等相关法律的范围内修订本条款。
  4. “公司”修订条款时，应注明适用日期及修订理由，并与现行条款一并自适用日期7日前起至适用日期前一日止在服务初始画面上进行公告。但如对用户不利地变更条款内容，则应至少设置30日以上的事先宽限期进行公告。此时，“公司”应明确对比修订前后的内容，以便用户易于理解。
  5. 本条款未规定的事项及本条款的解释，依照《促进信息通信网利用及信息保护等相关法律》、《个人信息保护法》、《关于条款规制等的法律》及相关法令或商业惯例。

第4条（服务的提供及变更）

  1. “公司”提供如下服务。
    1. 提供用于线下聚会的实时互动功能
    2. 提供主持人的房间创建及管理功能
    3. 提供嘉宾的房间参与及互动功能
    4. 其他由“公司”规定的附加服务
  2. “公司”可因技术规格变更等事由变更服务的内容。此时，应注明变更后的服务内容及提供日期，并立即在服务初始画面上进行公告。
  3. “公司”变更服务内容时，应通过电子邮件等可进行通知的方式立即将其事由通知用户。
  4. 在前款情形下，“公司”应赔偿用户因此遭受的损失。但“公司”证明其无故意或过失的除外。

第5条（服务的中断）

  1. 在下列各项情形下，“公司”可暂时中断提供服务。
    1. 需要进行系统检查、维护、更换等的情形
    2. 通信线路发生故障的情形
    3. 因自然灾害、停电、使用量激增等难以正常提供服务的情形
    4. 发生其他不可抗力事由的情形
  2. 对于因第1款事由导致服务提供暂时中断而使用户或第三方遭受的损失，“公司”予以赔偿。但“公司”证明其无故意或过失的除外。
  3. “公司”因业务类别转换、放弃业务、企业间合并等理由而无法提供服务时，应按照第8条规定的方法通知用户。

第6条（会员注册）

  1. 用户按照“公司”规定的注册表格填写会员信息后，通过作出同意本条款的意思表示申请注册会员。
  2. 对于按照第1款申请注册为会员的用户，除属于下列各项情形外，“公司”将其登记为会员。
    1. 注册申请人此前曾依照本条款第7条第3款丧失会员资格的情形
    2. 登记内容存在虚假、漏填、误填的情形
    3. 其他经判断登记为会员将对“公司”的技术造成显著障碍的情形
  3. 会员注册合同的成立时间为“公司”的承诺到达会员之时。
  4. 会员注册时登记的事项发生变更的，会员应立即通过修改会员信息等方式将该变更事项告知“公司”。

第7条（会员注销及资格丧失等）

  1. 会员可随时向“公司”申请注销，“公司”应立即办理会员注销。
  2. 会员属于下列各项事由之一的，“公司”可限制及暂停其会员资格。
    1. 申请注册时登记虚假内容的情形
    2. 妨碍其他用户使用服务或盗用其信息的情形
    3. 利用服务实施法令或本条款所禁止的行为或违反公序良俗的行为的情形
    4. 擅自收集、存储、公开嘉宾个人信息的情形
    5. 故意妨碍服务运营的情形
    6. 实施其他违反相关法令的行为的情形
  3. “公司”限制、暂停会员资格后，同一行为重复2次以上或该事由在30日内未得到纠正的，“公司”可使其丧失会员资格。
  4. “公司”使会员丧失会员资格时，将注销其会员登记。此时，应通知该会员，并在注销会员登记前给予其至少30日以上的申辩机会。

第8条（对会员的通知）

  1. “公司”对会员进行通知时，可通过会员提供的电子邮件地址或手机号码进行。
  2. 对不特定多数会员进行通知时，“公司”可通过在服务内公告栏中公示1周以上来代替个别通知。但对于会员本人的服务使用有重大影响的事项，应进行个别通知。

第9条（服务使用及个人信息提供同意等）

  1. “公司”在服务使用方面，应以用户易于理解的方式提供下列内容。
    1. 服务的主要功能及使用方法
    2. 个人信息收集项目（昵称、电话号码等）
    3. 对条款内容、服务使用限制事项的确认
    4. 同意本条款并确认或拒绝上述事项的意思表示
  2. “公司”需要向第三方提供用户个人信息时，应将下列各项事项告知用户并取得其同意。
    1. 个人信息的接收方
    2. 个人信息接收方的个人信息使用目的
    3. 所提供个人信息的项目
    4. 个人信息接收方的个人信息保存及使用期限
  3. 对于实时收集的用户服务使用数据，“公司”应明确告知收集范围及使用目的。

第10条（服务使用的成立）

  1. 属于下列各项情形之一的，“公司”可限制服务的使用。
    1. 申请内容存在虚假、漏填、误填的情形
    2. 侵害或盗用他人权利的情形
    3. 其他经判断对服务提供造成显著技术障碍的情形
  2. 未成年人使用服务的，应取得法定代理人的同意；未取得同意的，未成年人本人或法定代理人可撤销使用合同。

第11条（会员资格及代币的购买）

  1. “公司”的部分服务可通过购买会员资格或代币使用，支付方式如下列各项。
    1. 信用卡支付
    2. 银行转账
    3. 手机支付
    4. 其他由“公司”规定的电子支付方式
  2. “公司”不针对用户的支付方式额外收取任何名目的手续费。
  3. 会员资格和代币的有效期、使用条件、退款标准等，将在购买各商品时另行告知。
  4. 已充值代币的使用期限及可退款期限限于自付款时起1年以内。
  5. 未成年人购买会员资格或代币的，应取得法定代理人的同意；未经同意而购买的，未成年人本人或法定代理人可撤销该购买。
  6. 会员资格和代币仅可按照“公司”规定的目的和标准使用，不得将其转让给第三方或兑换为现金。

第12条（会员资格及代币的购买确认）

  1. 用户提出会员资格或代币购买申请时，“公司”应向用户发送购买确认通知。
  2. 收到购买确认通知的用户如发现内容不一致等情况，可立即要求取消购买；在会员资格或代币未被使用的情况下，“公司”应及时按照该要求进行处理。

第13条（会员资格及代币的提供）

  1. “公司”在付款完成后立即提供用户所购买的会员资格或代币，以供其使用。
  2. 因系统故障等事由难以立即提供的，“公司”应将该事由及预计提供时间通知用户。

第14条（返还）

  1. 在下列各项情形下，“公司”将返还用户所支付的价款。
    1. 因系统错误未提供会员资格或代币的情形
    2. 因服务中断导致所购买的会员资格无法使用的情形
    3. 其他因“公司”的可归责事由无法提供服务的情形
  2. 返还应自收到价款之日起3个工作日内进行；返还延迟的，应一并支付依照相关法令计算的延迟利息。

第15条（撤回要约及退款）

  1. 用户未使用所购买的会员资格或代币的，可自购买之日起7日内撤回要约。
  2. 在下列各项情形下，撤回要约可能受到限制。
    1. 会员资格或代币已开始使用的情形
    2. 因用户的可归责事由导致会员资格或代币灭失的情形
    3. 其他为交易安全而由法令规定的情形
  3. 撤回要约时，退款将根据用户所使用的支付方式按如下方式处理。
    1. 信用卡：取消付款
    2. 银行转账：汇入退款账户
    3. 手机支付：取消移动通信运营商付款或汇入退款账户

第16条（个人信息保护）

  1. “公司”收集用户个人信息时，在提供服务所需的范围内收集最少限度的个人信息。特别是考虑到线下聚会服务的特性，可收集用户的实时参与信息及互动数据。
  2. “公司”收集、使用用户个人信息时，应向用户告知其目的并取得同意。
  3. “公司”不得将所收集的个人信息用于目的以外的用途；产生新的使用目的或向第三方提供时，应向用户告知其目的并取得同意。
  4. “公司”取得用户同意时，应向用户告知下列事项。
    1. 个人信息管理负责人的身份
    2. 信息的收集目的及使用目的
    3. 向第三方提供时的接收方、目的、项目
    4. 实时收集信息的范围及保存期限
  5. 用户可随时要求查阅及更正其个人信息的错误，“公司”应及时采取必要措施。
  6. “公司”为保护用户的个人信息设置管理负责人，并对因个人信息的丢失、被盗、泄露、擅自提供、篡改等给用户造成的损失承担责任。
  7. 对于已实现服务目的的个人信息，“公司”应及时予以销毁。

第17条（“公司”的义务）

  1. “公司”遵守相关法令及本条款，并尽最大努力稳定地提供服务。
  2. “公司”配备安全系统，以便用户安全地使用服务，并努力保护个人信息。
  3. 未经本人同意，“公司”不得将在提供服务过程中获知的用户信息提供给第三方或予以泄露。
  4. “公司”不发送用户不希望接收的营销信息。

第18条（会员的账号管理义务）

  1. ID和密码的管理责任由会员承担。
  2. 会员不得将自己的ID及密码提供给第三方或让第三方使用。
  3. 会员发现ID及密码被盗用或被第三方使用时，应立即通知“公司”并遵循“公司”的指引。
  4. 会员对其账号发生的一切活动承担责任。

第19条（用户的义务）

用户不得实施下列行为。

  1. 在注册会员、变更信息时登记虚假内容
  2. 盗用或擅自使用他人信息
  3. 擅自变更或删除服务内的信息
  4. 安装、传播恶意程序或妨碍服务正常运营的行为
  5. 侵害“公司”及第三方的知识产权
  6. 损害他人名誉或妨碍聚会进行的行为
  7. 发布或传送淫秽、暴力、歧视性内容或违反公序良俗内容的信息的行为
  8. 发布或传送以营利为目的的广告性信息的行为
  9. 操纵或歪曲实时投票或问卷调查结果的行为
  10. 擅自收集、存储、公开其他用户个人信息的行为
  11. 危害线下聚会安全或秩序的行为
  12. 其他相关法令所禁止或妨碍服务正常运营的行为

第20条（著作权的归属及使用限制）

  1. “公司”制作的服务内内容的著作权及其他知识产权归“公司”所有。
  2. 用户在服务内创作的内容的著作权归用户所有。但“公司”可为服务的运营、展示、宣传、服务改进等目的无偿使用用户的内容。
  3. 未经“公司”事先同意，用户不得将通过“公司”服务获得的信息以复制、传送、出版、发行、播放或其他方式用于营利目的，或让第三方使用。

第21条（纠纷解决）

  1. “公司”为反映用户提出的正当意见或投诉并对其损失进行补偿处理，设立并运营客户服务中心。
  2. “公司”优先处理用户提交的投诉事项及意见。但难以迅速处理的，应立即将其事由及处理日程通知用户。
  3. 就“公司”与用户之间发生的纠纷，用户提出损害救济申请的，可依照相关法令由纠纷调解机构进行调解。

第22条（审判管辖及准据法）

  1. 与“公司”和用户之间发生的纠纷相关的诉讼，以起诉时用户的住所为准，无住所的，由管辖其居所的地方法院专属管辖。但起诉时用户的住所或居所不明确或为外国居住者的，应向《民事诉讼法》规定的管辖法院提起。
  2. “公司”与用户之间提起的诉讼适用大韩民国法律。

第23条（关于通知消息（AlimTalk）等消息发送的内容）

“公司”可通过KakaoTalk通知消息（AlimTalk）发送与服务运营相关的指南、通知事项、聚会参与信息等；无法接收通知消息或已屏蔽接收的，将以短信方式发送。通过移动通信网络连接时，接收消息过程中可能产生数据流量费用。如不希望接收通知消息，可屏蔽通知消息，或向“公司”申请以其他方式接收信息。

附则

本条款自2024.12.4起施行。
